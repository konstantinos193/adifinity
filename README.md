## Features

- **Dark theme** — won't burn your retinas at 2 AM

- **Legacy URL redirects** — migrated from Joomla without breaking old links

## Getting Started

### Prerequisites

Node.js 18+. If you're on anything older, go update and come back.

```bash
node --version  # Should be ≥18
npm --version
```

### Installation

```bash
git clone <your-repo-url>
cd adifinity/FRONTEND
npm install  # Go get coffee. Seriously.
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and see what happens.

### Production Build

```bash
npm run build
npm start
```

If it builds clean, you've achieved something. If it doesn't — `npm run build 2>&1 | head -50` is your friend.

## Internationalization

| Property | Value |
|---|---|
| Default language | Greek (`el`) |
| Secondary language | English (`en`) |
| Library | `next-intl` 4.12.0 |
| URL strategy | Single URL, client-side language switching |
| Translation files | `messages/el/` and `messages/en/` (29 namespaced files each) |
| SEO | `hreflang` tags, localized `<title>`/`<description>`, localized Open Graph |

When you touch translations, update **both** language directories. Breaking Greek translations because you only edited the English file is a great way to have a bad day.

## Contact API

`POST /api/contact` — Receives form submissions with name, email, message, and optional file attachment. Sends email via Nodemailer (Gmail transport). Returns `{ success: boolean, message: string }`.

Three email providers are available: **EmailJS** (client-side), **Nodemailer** (server-side, active), **Resend** (API-based). Pick your poison.

## Accessibility

This site takes accessibility seriously:

- **Skip navigation links** (`SkipLinks.tsx`) for keyboard users

- **WCAG-targeted** markup: semantic HTML, `aria-*` attributes, focus management
- **Accessibility page** at `/accessibility` documenting our compliance stance
- **Accessibility-specific CSS** in `styles/accessibility.css`

## Contributing

1. Don't break things (obvious, but worth stating)
2. For translations: update **both** `messages/el/` and `messages/en/`
3. For new pages: add a `layout.tsx` with proper metadata, update navigation
4. For SEO changes: verify metadata renders correctly in both languages
5. For new components: put shared ones in `components/ui/`, page-specific in `app/components/`
6. Write meaningful commit messages — "fix stuff" is acceptable only after midnight
